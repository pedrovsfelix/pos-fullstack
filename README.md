# Projeto Inicial com Node.js

Este repositório foi criado como parte dos estudos da pós-graduação em Desenvolvimento Fullstack. O foco deste projeto é entender os conceitos básicos do **Node.js**, como execução de scripts JavaScript no backend, manipulação de arquivos, criação de servidores e uso de pacotes via NPM.

## 🧠 Objetivos de Aprendizado

- Entender o que é o Node.js e sua utilidade no backend
- Utilizar o `npm` para gerenciar dependências
- Criar um servidor básico com `http`
- Trabalhar com leitura e escrita de arquivos
- Utilizar módulos internos e externos
- Estruturar um projeto simples com boas práticas

## 🛠️ Tecnologias Utilizadas

- [Node.js](https://nodejs.org/)
- JavaScript (ES6+)
- NPM
